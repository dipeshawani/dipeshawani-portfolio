## 💻 How to View Locally

Simply double-click `index.html` in your file explorer, and it will open directly in any modern web browser (Chrome, Edge, Firefox, Brave, Safari).

Alternatively, using VS Code:
1. Open the folder in VS Code.
2. Right-click `index.html` and click **"Open with Live Server"**.

## 🌐 Free Hosting / Deployment (How to make it live online)

### Option 1: GitHub Pages (Recommended)
1. Create a repository on GitHub named `portfolio` or `dipesha-wani-portfolio`.
2. Push all the files (`index.html`, `style.css`, `script.js`, `resume.html`) to your repository.
3. Go to **Settings** > **Pages**.
4. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
5. Your portfolio will be live at `https://<your-username>.github.io/<repo-name>/`!

### Option 2: Netlify (Drag & Drop - 30 seconds)
1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop this folder (`portfillo177`).
3. Your site will instantly go live with a free custom URL!
